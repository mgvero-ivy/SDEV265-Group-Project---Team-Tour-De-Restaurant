Tour De Restaurant

SDEV265 Group Project

Developed by Marko Gvero, Ashley Lawrence, Cesar Vazquez, Marvin Lamothe

Welcome to the Tour De Restaurant system.

Tour De Restaurant is a web-based restaurant inventory and order management system developed as a group project for the Fall 2026 semester of SDEV265. The application demonstrates how restaurant operations can be managed through a single system by combining inventory management, order placement, and kitchen order fulfillment.

This system was built using Django, Python, HTML, CSS, JavaScript, and SQLite. Menu items are connected to the ingredients used in their preparation, allowing inventory quantities to be automatically updated when orders are placed. Staff members can securely log in to view inventory, adjust inventory quantities, enter new orders, and manage kitchen orders efficiently.

Navigate the system using the navigation bar in the top-left corner of the page. Clicking "Order" will take you to the menu, where you can view available items and place an order once logged in. Staff members can also access inventory management and kitchen order fulfillment features from the navigation bar after logging in. Administrators have access to additional features through the Django admin interface, where they can manage users, ingredients, orders, menu items, and the ingredients associated with each menu item without modifying the application code.
